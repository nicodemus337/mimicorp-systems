How I work

Useful AI starts with the work.

I begin with the task: who does it, where time or information gets lost, what must stay private, and what the team already knows.

Then I build the smallest useful intervention, test it in the workflow, and document it for the people who will run it.

  1. 01Input / trace
    Map the workflow

    Name the task, user, and constraints.

  2. 02Prototype / assemble
    Build the tool

    Add AI or automation where it helps.

  3. 03Field / run
    Test it at work

    Use it in the daily workflow and revise.

  4. 04Transfer / control
    Hand it over

    Give the team clear instructions and control.
